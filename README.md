# 🐘 Exercícios de PHP

Repositório com exercícios desenvolvidos em **PHP** para praticar conceitos básicos de programação.

## 📚 Exercícios

### 1. Cálculo de desconto

Programa que calcula o valor total de uma compra e aplica **10% de desconto** quando o valor for igual ou superior a **R$ 200,00**.

**Conceitos utilizados:**
- Variáveis
- Operações matemáticas
- Estruturas condicionais
- `if` e `else`
- Porcentagem

### 2. Média e faltas

Programa que verifica a situação de um aluno de acordo com sua média e quantidade de faltas.

**Critérios:**
- Média maior ou igual a **6,0**
- Faltas menor ou igual a **15**

**Conceitos utilizados:**
- Variáveis
- Operadores relacionais
- Operador lógico `&&`
- Estruturas condicionais

### 3. Tabuada

Programa que exibe a tabuada de um número de **1 a 10** utilizando a estrutura de repetição `for`.

**Conceitos utilizados:**
- Variáveis
- Estrutura `for`
- Operações matemáticas
- Repetição

### 4. Notas da turma

Programa que armazena as notas de **5 alunos** em um array e utiliza `foreach` para percorrer as notas.

O programa calcula:

- Média da turma
- Maior nota
- Menor nota

**Conceitos utilizados:**
- Arrays
- `foreach`
- Operações matemáticas
- Estruturas condicionais

### 5. Cálculo de IMC

Programa que utiliza uma função chamada `calcularIMC($peso, $altura)` para calcular o IMC.

A função recebe o peso e a altura como parâmetros, calcula o resultado e retorna o valor calculado.

**Conceitos utilizados:**
- Funções
- Parâmetros
- `return`
- Operações matemáticas
- `if`
- `elseif`
- `else`
